Place custom bottom navigation SVG icons in this directory using the outline/fill naming convention expected by MainShell:

- recipes_outline.svg / recipes_fill.svg
- matches_outline.svg / matches_fill.svg
- swipes_outline.svg / swipes_fill.svg
- add_dish_outline.svg / add_dish_fill.svg
- profile_outline.svg / profile_fill.svg

Material icons are used as fallback when a selected SVG asset is absent.
